# 施塔西逻辑框图 / Stasi Diagrams

将可编辑的 `.drawio` 源文件保存在本目录。  
Store editable `.drawio` source files in this directory.

## 保存新图 / Save a new diagram

在 [diagrams.net](https://app.diagrams.net/) 中，选择 **文件 → 另存为 → GitHub**，再选择 `LucasvonLiu/Mapping_Stasi` 仓库的 `main` 分支和 `diagrams/` 目录。

In [diagrams.net](https://app.diagrams.net/), select **File → Save As → GitHub**. Choose the `LucasvonLiu/Mapping_Stasi` repository, the `main` branch, and the `diagrams/` directory.

## 打开已有图稿 / Open an existing diagram

选择 **文件 → 从…打开 → GitHub**，在 `diagrams/` 中打开要继续编辑的 `.drawio` 文件。

Select **File → Open From → GitHub** and open the `.drawio` file you want to edit in `diagrams/`.
